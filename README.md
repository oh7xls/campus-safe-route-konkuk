# 캠퍼스 안전길 팀 프로젝트

이 저장소는 같은 **캠퍼스 안전길** 주제에 대해 팀원들이 각자 다른 방식으로 구현한 결과물을 `main` 브랜치 안에서 사람별 폴더로 분리해 관리합니다.

## 폴더 구조

```text
project-root/
├─ 김예진/   # 김예진 작업물
├─ 김민정/   # 김민정 작업물
├─ 김미래/   # 김미래 작업물
├─ .gitignore
└─ README.md  # 팀 공용 안내
```

## 작업 규칙

- 각 팀원은 반드시 **자신의 이름 폴더 안에서만** 파일을 만들고 수정합니다.
- 다른 팀원 폴더의 파일은 사전 협의 없이 수정하거나 삭제하지 않습니다.
- `.gitignore`, `.github`, 라이선스, 루트 README처럼 저장소 전체에 적용되는 파일은 루트에 둡니다.
- API 키와 비밀번호가 들어 있는 `.env.local` 등의 비밀 파일은 커밋하지 않습니다.
- 각자 프로젝트를 실행할 때는 저장소 루트가 아니라 자신의 폴더로 이동해 명령을 실행합니다.

## 기본 작업 흐름

작업을 시작하기 전에 다른 팀원의 최신 변경을 먼저 받습니다.

```bash
git pull origin main
```

자신의 폴더에서 작업하고 확인한 뒤, 저장소 루트에서 자신의 변경만 커밋합니다.

```bash
git status
git add "본인이름/"
git commit -m "feat: 작업 내용 요약"
git push origin main
```

예를 들어 김민정 팀원은 `김민정/` 안에서만 작업하고 다음처럼 추가합니다.

```bash
git add "김민정/"
```

푸시 전에 다시 `git pull origin main`을 실행해야 한다면 충돌 내용을 확인하고, 본인이 판단하기 어려운 다른 사람 폴더의 충돌은 해당 팀원과 함께 해결합니다.

## 최종 통합

각 팀원의 개별 작업물이 완성되면 비교·검토한 뒤, 필요할 경우 팀 합의에 따라 최종 결과물을 별도 공용 폴더나 별도 통합 단계에서 구성합니다. 통합 전까지는 각자의 구현을 이름 폴더 안에 독립적으로 유지합니다.

## 현재 김예진 프로젝트 실행

```bash
cd "김예진"
corepack pnpm install --frozen-lockfile
corepack pnpm check
corepack pnpm build
corepack pnpm start
```

브라우저에서 `http://localhost:3000`을 엽니다. 실제 TMAP 기능에 필요한 개인 `.env.local`은 `김예진/` 안에 만들되 Git에는 올리지 않습니다.
