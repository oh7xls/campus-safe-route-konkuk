# 데이터 출처 및 이용 상태

## 광진구 CCTV 설치 현황

- 제공기관: 서울특별시 광진구
- 공식 페이지: https://www.gwangjin.go.kr/portal/main/contents.do?menuNo=200896
- 원본 형식: XLSX
- 원본 페이지 개정일: 2025-09-25
- 2026-09-14(KST) 재수집 결과: 원본 1,327행, 건국대 파일럿 안전 관련 위치 214개
- 적용 용도: 생활방범, 공원방범, 어린이보호, 다목적
- 좌표계: WGS84 위·경도
- 무결성: 스냅샷의 `sourceSha256`에 수집 원본 파일 해시를 기록한다.

## 광진구 스마트보안등

- 제공기관: 서울특별시 광진구 빅데이터포털
- 공식 화면: https://www.gwangjin.go.kr/gooddata/orl/sqt/ssqt.do?type=smsl
- 공개 레이어: `gjgc:smart_security_light`
- 원본 형식: WFS GeoJSON
- 좌표계: EPSG:4326
- 최신 재수집일: 2026-09-14(KST)
- 최신 재수집 결과: 원본 3,699개, 건국대 파일럿 902개
- 원본 위치자료에 갱신시각과 작동 상태가 없어 각각 `null`, 미제공으로 취급한다.
- 무결성: 스냅샷의 `sourceSha256`에 원본 응답 해시가 기록돼 있다.

## 이용조건 확인 상태

두 자료는 광진구 공식 공개 화면에서 제공되지만, 현재 스냅샷에는 데이터별 공공누리 유형이나 별도 이용허락 문구가 포함돼 있지 않다. 팀 내부 개발·검증에는 출처를 명시해 사용하고, 외부 공개·재배포 전에는 각 공식 페이지의 최신 이용약관과 공공데이터 이용조건을 다시 확인한다.

## 현재 확인하지 못한 정보

- CCTV 개별 장비의 실시간 작동 상태와 촬영 방향
- CCTV의 실제 촬영범위
- 스마트보안등 개별 위치자료의 원본 갱신시각
- 스마트보안등의 실시간 점등·고장 상태

따라서 현재 데이터로 위 정보를 제공하거나 안전을 보장한다고 표현하지 않는다.
