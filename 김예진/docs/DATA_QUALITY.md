## 재현성과 전달 무결성

- 파생 파일의 `generatedAt`은 최신 원본 수집 시각을 사용하므로 같은 원본으로 다시 만들면 내용이 바뀌지 않는다.
- `data/processed/CHECKSUMS.sha256`에 팀 전달 파일 6개의 SHA-256을 기록한다.
- GeoJSON은 RFC 7946 방식에 맞춰 별도 `crs` 멤버 없이 WGS84 경도·위도 순서를 사용한다.
- 현장검증 결과 CSV는 자동 재생성으로 덮어쓰지 않는다.

## 정상적인 누락값

스마트보안등 WFS 902개에는 주소, 용도, 원본 갱신시각이 없다. CCTV 원본은 주소 열을 제공하지만 파일럿 시설 7개는 값이 `-`다. 이는 변환 오류가 아니라 원본 미제공으로, 빈 문자열이나 `-`를 그대로 전달하지 않고 공통 규격에서 `null`로 보존한다. CCTV의 시설명, 용도와 페이지 개정일은 유지한다.
