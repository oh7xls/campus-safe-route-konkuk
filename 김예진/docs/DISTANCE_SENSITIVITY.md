# 시설 거리 기준 민감도 예비 분석

자동 생성 결과는 `data/analysis/distance-sensitivity.json`과 CSV를 기준으로 한다.

## 분석 조건

- CCTV 반경: 50m, 70m, 100m
- 스마트보안등 반경: 20m, 35m, 50m
- 대표 구간: 건대입구역·건국대 주변 5개 구간
- 경로 표본 간격: 약 20m
- 시설: CCTV 214개, 스마트보안등 902개

현재 환경에는 실제 TMAP 키와 저장된 실제 경로 geometry가 없어 장소 사이 직선을 대리경로로 사용했다. 따라서 아래 결과는 계산 구조와 변화 폭을 확인하는 예비 분석이지 최종 안전성 결론이 아니다.

## 5개 구간 집계

주변 시설 개수는 구간별 평균이고, 커버리지는 다섯 구간의 모든 표본 147개를 합산한 가중 비율이다. 이 방식은 짧은 구간과 긴 구간을 똑같은 비중으로 평균해 결과가 왜곡되는 것을 줄인다. 기계 판독 JSON에는 비교를 위해 구간별 단순 평균도 함께 남긴다.

| CCTV/보안등 반경 | 주변 CCTV | 주변 보안등 | CCTV 커버리지 | 보안등 커버리지 | 결합 커버리지 |
|---|---:|---:|---:|---:|---:|
| 50m / 20m | 3.6 | 2.8 | 36% | 11% | 39% |
| 50m / 35m | 3.6 | 5.8 | 36% | 24% | 44% |
| 50m / 50m | 3.6 | 7.8 | 36% | 29% | 45% |
| 70m / 20m | 6.0 | 2.8 | 49% | 11% | 50% |
| **70m / 35m** | **6.0** | **5.8** | **49%** | **24%** | **52%** |
| 70m / 50m | 6.0 | 7.8 | 49% | 29% | 52% |
| 100m / 20m | 8.0 | 2.8 | 61% | 11% | 61% |
| 100m / 35m | 8.0 | 5.8 | 61% | 24% | 61% |
| 100m / 50m | 8.0 | 7.8 | 61% | 29% | 61% |

## 현재 판단

MVP 기본값인 CCTV 70m·보안등 35m를 유지한다. 50m 대비 시설 누락을 줄이면서, 100m처럼 실제로 멀리 떨어진 시설까지 포함할 가능성을 낮추는 중간값이다. 보안등을 35m에서 50m로 늘려도 이번 대리경로의 가중 결합 커버리지는 52%로 같아 35m를 유지할 근거가 있다.

단, 반경이 실제 촬영·조명 범위를 의미하지 않으며 실제 보행 경로 geometry와 현장 표본을 적용하기 전에는 최종 기준으로 확정하지 않는다.

## 실제 경로로 다시 분석

다음 형태의 JSON을 준비하면 같은 스크립트로 재분석할 수 있다.

```json
{
  "generatedAt": "2026-09-13T05:29:42.000Z",
  "routes": [
    {
      "id": "station-geonguk",
      "name": "건대입구역 2번 출구 → 건국문",
      "points": [
        { "lat": 37.5401, "lng": 127.0704 },
        { "lat": 37.5451, "lng": 127.0765 }
      ]
    }
  ]
}
```

```powershell
corepack pnpm data:sensitivity -- "C:\path\to\actual-routes.json"
```
