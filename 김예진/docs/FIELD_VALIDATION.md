# 지도·현장 표본검증 체크리스트

자동 생성 표본은 `data/qa/facility-validation-sample.csv`에 있다. 실제 검증 결과는 별도 파일인 `data/qa/facility-validation-results.csv`에 입력한다. CCTV 10개와 스마트보안등 10개를 파일럿 전역에 분산되도록 자동 선택했으며, 최초 상태는 모두 `not_checked`다.

`data:week3`를 다시 실행하면 표본 파일은 최신 데이터로 다시 만들어지지만, 이미 존재하는 결과 파일은 덮어쓰지 않는다. 표본 구성이 바뀌었다면 기존 결과를 보존한 뒤 담당자가 직접 새 표본과 병합한다.

## 지도 검증

각 행의 `mapUrl`을 열고 다음을 확인한다.

- [ ] 좌표가 광진구·건국대 파일럿 반경 안에 있는가
- [ ] CCTV 주소와 지도 위치가 같은 도로 또는 지점인가
- [ ] 마커가 건물 중심이나 도로 반대편으로 크게 벗어나지 않았는가
- [ ] 보안등 좌표가 도로·골목·보행공간과 합리적으로 맞닿아 있는가
- [ ] 같은 시설이 인접 위치에 중복돼 보이지 않는가

확인 후 결과 CSV의 `mapVerificationStatus`를 `passed`, `needs_review`, `not_found` 중 하나로 변경하고 `notes`에 근거를 적는다.

## 현장 검증

현장 확인은 지도 검증을 통과한 표본 중 접근 가능한 위치부터 수행한다.

- [ ] 시설이 실제로 존재하는가
- [ ] 좌표와 실제 위치의 오차가 시연에 영향을 줄 정도인가
- [ ] CCTV인 경우 공개 시설명·주소와 일치하는가
- [ ] 스마트보안등 장비 식별자를 현장에서 확인할 수 있는가
- [ ] 점등·작동 여부를 확인했다면 확인 시각을 함께 기록했는가

현장 결과는 `passed`, `moved`, `not_found`, `inaccessible` 중 하나로 기록한다. 한 번의 현장 확인을 시설의 상시 작동 상태로 일반화하지 않는다.

## 완료 기준

- CCTV와 스마트보안등 각각 지도 표본 10개 확인
- 가능한 범위에서 종류별 현장 표본 3개 이상 확인
- 좌표 오차나 미존재 시설이 발견되면 원본 오류인지 수집 오류인지 분리
- 검증 결과와 날짜를 발표 자료에 기록
